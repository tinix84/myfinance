# myfinance

Python experiments in quantitative finance — stock analysis, options pricing, portfolio analytics, and fundamental analysis.

## Contents

| File | Description |
|:-----|:------------|
| `test_FundamentalAnalysis.ipynb` | Fundamental analysis notebook (financial ratios, DCF) |
| `test_yfinance.py` | Yahoo Finance data fetching and analysis |
| `test_iex.py` | IEX Cloud API integration |
| `test_mcs.py` | Monte Carlo simulation for option pricing |
| `test_nvax.py` | NVAX stock analysis case study |
| `test_us_stocks/` | US stock screening and analysis |
| `test_wsl_selenium/` | Web scraping for financial data |
| `utils.py` | Shared utility functions |
